# KabalPrint — диспетчер производственных заявок

Десктопное приложение для печатного производства: печатники видят заявки из Google Таблицы,
берут их в работу, завершают и печатают техкарту заказа.

Electron 31 · React 19 · TypeScript · Vite 7 · Tailwind CSS 4 · Google Sheets API

## Возможности

- **Список заявок** с фильтрами по статусу, продукции, материалу, ламинации и работам
- **Теги** — продукция, операции, материалы, плотность и ламинация извлекаются из ТЗ автоматически
- **Взятие в работу** — заявка закрепляется за печатником, строка подсвечивается его цветом
- **Завершение** — форма фактического расхода бумаги и выполненных работ, запись в таблицу
- **Печать техкарты** — берётся готовый файл ТЗ из папки заказа
- **Ссылка на папку** заказа открывается в проводнике
- **Настраиваемая ширина столбцов**, сортировка по клику на заголовок

## Требования

- Node.js 20+
- Windows (используются сетевые пути `\\server\...` и печать через системный обработчик)
- Сервисный аккаунт Google с доступом к таблице

## Установка

```bash
npm install
```

### Ключ сервисного аккаунта

Положите JSON-ключ в `credentials/google-key.json`. Файл в `.gitignore` — в репозиторий он не попадает.

```json
{
  "type": "service_account",
  "project_id": "...",
  "private_key_id": "...",
  "private_key": "-----BEGIN PRIVATE KEY-----\n...\n",
  "client_email": "your-bot@project.iam.gserviceaccount.com",
  "client_id": "..."
}
```

Затем откройте таблицу в Google Sheets → **Доступ** → добавьте `client_email` как редактора.

### Настройка таблицы

В `electron/main.mjs` задаются:

```js
const SPREADSHEET_ID = '...';   // ID таблицы из её URL
const SHEET_TITLE = 'Печать_2026';
```

## Запуск

```bash
npm run dev     # Vite dev-сервер (браузер, демо-данные)
npm start       # Electron с реальной таблицей
```

В браузере приложение работает на демо-данных; запись в таблицу доступна только в Electron.

## Сборка

```bash
npm run build   # только фронтенд → dist/
npm run dist    # установщик NSIS → release/kabal-print-setup-<version>.exe
```

## Схема листа

| Столбец | Назначение |
|---------|-----------|
| A | № заявки |
| B | Заказчик |
| C / D | Дата постановки / срок сдачи |
| E | ТЗ (первая строка — путь к папке заказа) |
| F | Кол-во листов бумаги — заполняет печатник при завершении |
| G | Плотность / тип бумаги — заполняет печатник |
| H | Цветность — заполняет печатник |
| I | Послепечатные работы — заполняет печатник |
| J | Буква печатника (`В` / `к` / `m`) |
| K | Менеджер |
| Y | Статус: имя печатника / `не в работе` / `Готово` |

**Статус заявки определяется только по столбцу Y.** Цвет ячеек для этого не используется.

## Структура

```
electron/
  main.mjs        — главный процесс: Google Sheets, IPC, печать
  preload.cjs     — мост contextBridge → window.kabalAPI
  documents.mjs   — поиск файла ТЗ в папке заказа и чтение кодировок
src/
  App.tsx         — интерфейс, фильтры, действия над заявками
  parseTz.ts      — разбор ТЗ: продукция, тираж, бумага, цветность
  dictionaries.ts — справочники тегов (продукция, работы, материалы)
  style.css       — стили
```
